# 📚 VoxCPM Books — аудиокниги из PDF на VoxCPM2

Локальное приложение: загружаешь PDF → проверяешь текст и главы → выбираешь голос
(клон по образцу или дизайн по описанию) → получаешь **MP3 по главам** и/или
**M4B с главами и обложкой**. Модель — [VoxCPM2](README.md) (2B, 48 кГц, 30 языков, русский в том числе).

Оптимизировано под **RTX 3090 (24 ГБ) + i5‑11400F + 16 ГБ ОЗУ**, Windows 10/11.

---

## Установка (Windows)

1. Свежий драйвер NVIDIA (≥ 580 — для CUDA 13 и последнего PyTorch; минимум 560).
2. Положи папку проекта по пути **без кириллицы и пробелов**, например `C:\VoxBooks`
   (иначе `triton`/`torch.compile` на Windows может не завестись — приложение тогда просто
   будет работать медленнее).
3. Запусти **`install.bat`**. Он сам:
   * поставит [uv](https://docs.astral.sh/uv/) (если его нет);
   * создаст `.venv` с Python 3.11 (uv скачает Python сам, системный не нужен);
   * поставит **последний PyTorch** (сейчас 2.15) с самой новой CUDA, которую поддерживает
     твой драйвер: CUDA 13.x при драйвере ≥ 580, иначе 12.8 / 12.6. После установки — GPU-тест
     (bf16 на видеокарте); если сборка не встала или тест не прошёл — автоматический откат на
     проверенную связку 2.10 + CUDA 12.6 (на ней VoxCPM2 тестировали авторы).
     Сразу стабильная версия: `set "TORCH_CHANNEL=stable"` в начале `install.bat`;
   * поставит зависимости (без тяжёлых `funasr`/`datasets`/`modelscope` — для озвучки они не нужны);
   * поставит `triton-windows` той ветки, которую требует установленный torch (ускорение `torch.compile`);
   * скачает модель в `models\VoxCPM2` (~5 ГБ; при недоступности HF — зеркало, затем ModelScope);
   * проверит окружение.
4. Запуск: **`run.bat`** → браузер откроется на `http://127.0.0.1:7861`.

Повторный запуск `install.bat` безопасен: уже установленное пропускается.

Linux: `./install.sh`, затем `./run.sh`.

## Как пользоваться (веб-интерфейс)

1. **Книга** — загрузи PDF (или TXT), нажми «Создать проект и разобрать».
   Проверь список глав. Если что-то не так — открой «Редактировать текст»,
   поправь (формат: `# Название главы`, пустая строка между абзацами) и «Применить правки».
   Лишние страницы (обложка, оглавление, указатель) отсекаются полями «С/По страницу».
2. **Голос**:
   * *Клонирование* — образец 10–20 с чистой речи (без музыки и эха). Если вписать **точный
     текст образца**, похожесть максимальная.
   * *Дизайн по описанию* — «Сгенерировать образец», послушать, повторить до удачного варианта,
     затем «Использовать этот голос для книги». Так тембр зафиксируется на всю книгу.
   * «Прослушать» — проверка на фразе из книги. Затем «Сохранить голос в проект».
3. **Озвучка** — «Начать / продолжить». Можно остановить в любой момент и продолжить позже
   (даже после перезагрузки ПК): готовые сегменты лежат на диске. Сегменты с подозрительным
   темпом помечаются ⚑ — их можно прослушать, поправить текст и переозвучить.
4. **Сборка** — MP3 по главам, M4B одним файлом с главами и обложкой (первая страница PDF), WAV.

## Командная строка

```bat
audiobook.bat make "D:\Книги\книга.pdf" --ref "D:\голос.wav" --ref-text "Точный текст образца." --formats mp3,m4b
audiobook.bat new книга.pdf --first-page 5 --last-page 380   :: только разбор, текст в projects\книга\book.txt
audiobook.bat text книга --apply projects\книга\book.txt     :: применить ручные правки
audiobook.bat synth книга --ref голос.wav --timesteps 10     :: озвучка (Ctrl+C — пауза, потом продолжит)
audiobook.bat synth книга --redo-flagged                     :: переозвучить помеченные
audiobook.bat export книга --formats m4b
audiobook.bat status книга
```

## Как книга режется на сегменты (чтобы ничего не рвалось)

**1. Извлечение из PDF** (`audiobook/pdf_extract.py`, PyMuPDF):

* **Колонтитулы и номера страниц** — строки в верхних/нижних полях, повторяющиеся на ≥ 3
  страницах (цифры при сравнении игнорируются), и «голые» номера страниц.
* **Сноски** — мелкий шрифт под последней строкой основного текста внизу страницы; маркеры
  сносок (надстрочные `¹`, `*`, мелкие цифры) вырезаются из текста.
* **Переносы**: `сма-` + `тывал` → `сматывал`, но `кто-` + `то` → `кто-то` (частицы
  -то/-либо/-нибудь/-ка/-таки сохраняют дефис); мягкие переносы удаляются.
* **Абзацы** собираются по геометрии: отступ первой строки, короткая последняя строка,
  увеличенный интервал, реплика с тире. Если строка **не закончилась точкой**, абзац
  **продолжается через границу страницы/колонки** — разрыв предложения на стыке страниц исключён.
* **Главы**: оглавление PDF (outline) → крупный шрифт → шаблоны («Глава 1», «ГЛАВА ПЕРВАЯ»,
  «Часть II», «Пролог», «Chapter 3», отдельно стоящие «IV»). Подряд идущие заголовки
  («Часть I» + «Глава 1») склеиваются. `* * *` — смена сцены (длинная пауза).
* Скан без текстового слоя распознаётся и выдаётся предупреждение (нужен OCR).

**2. Нормализация** (`audiobook/normalize.py`): раскрытие сокращений (т. е., и т. д., см., г., в.,
млн…), римские цифры в «Глава XII» и «XIX век», удаление ссылок `[12]` и URL, ВЕРХНИЙ РЕГИСТР →
обычный (аббревиатуры вроде СССР не трогаются), многоточия, тире.
**Скобки → тире**: VoxCPM2 воспринимает `(…)` в начале текста как *инструкцию голоса*, поэтому
круглые скобки в тексте книги недопустимы.

**3. Сегментация** (`audiobook/segmenter.py`):

1. Сегмент **никогда не пересекает границу главы**.
2. Предложение **не режется**, если оно ≤ `max_chars` (по умолчанию 380). Деление на
   предложения — `razdel` (учитывает инициалы «А. С. Пушкин», сокращения, прямую речь
   «— Привет! — сказал он.»).
3. Слишком длинное предложение режется по самой естественной границе ближе к середине:
   `;` → `:` → ` — ` → `,` → пробел.
4. Абзац делится **оптимально (динамическое программирование)**: длины выравниваются вокруг
   `target_chars` (230), разрез по концу предложения дешевле разреза по запятой, без крошечных
   «хвостов».
5. Короткие реплики диалога (`— Да.`, `— Нет.`) объединяются в один сегмент.
6. Паузы: между сегментами абзаца 220 мс, конец абзаца 650 мс, после заголовка 1.1 с,
   смена сцены 1.5 с, конец главы 2 с (всё настраивается).

Почему ~230 символов: это 15–20 с речи — у VoxCPM2 достаточно контекста для естественной
интонации, но ещё нет риска «заговаривания» и дрейфа тембра на длинных фрагментах.

**4. Склейка** (`audiobook/audio.py`): у каждого сегмента обрезается тишина по краям, громкость
выравнивается по RMS речевых кадров (−20 dBFS, пик ≤ −1.5 dBFS), микрофейды 8/25 мс против
щелчков, затем вставляются паузы из п. 3.6. Сборка потоковая — в памяти один сегмент.

## Оптимизации под RTX 3090 / 16 ГБ ОЗУ

| Что | Зачем |
|---|---|
| bfloat16 + TF32 | нативно на Ampere, вдвое меньше VRAM и быстрее fp32 |
| `torch.compile(mode="reduce-overhead")` + CUDA Graphs (`triton-windows`) | ~1.5–2× быстрее; при ошибке компиляции — автоматический откат на eager |
| Модель строится **сразу в VRAM**, safetensors грузятся прямо на GPU | пик ОЗУ ~3 ГБ вместо ~12 ГБ при стандартной загрузке |
| Кэш опорного голоса строится один раз на книгу | образец не кодируется заново для каждого сегмента |
| GPU-поток синтеза + отдельный поток записи (очередь) | GPU не ждёт диск и FLAC-кодирование |
| `torch.set_num_threads(6)` | 6 физических ядер i5‑11400F, остальное — писателю и ffmpeg |
| Сегменты — FLAC на диске, сборка потоковая | 20-часовая книга не держится в ОЗУ (48 кГц float ≈ 14 ГБ!) |
| Кэши inductor/triton/HF внутри папки программы | не ломается из-за кириллицы в `C:\Users\…` |

Ориентиры скорости (RTF = время синтеза / длительность аудио): на RTX 4090 у VoxCPM2 ≈ 0.3,
на 3090 ожидаемо ≈ 0.4–0.5 при «Баланс» (10 шагов). Книга на 10 часов → ~4–5 часов синтеза.
«Быстро» (6 шагов) — ещё ~30 % быстрее, для черновика. VRAM: ~8–9 ГБ.

## Контроль качества

* Встроенная проверка модели (отношение длины аудио к тексту) + собственная: темп речи
  в симв./с. Если сегмент «заговорился» (< 5 симв./с), оборвался (> 32 симв./с) или темп
  отличается от медианы диктора в 1.8+ раза — повтор с другим seed (до 3 попыток),
  иначе берётся лучший вариант и сегмент помечается ⚑.
* Seed каждого сегмента зависит от его текста → повторный запуск воспроизводим.
* Аудио сегмента адресуется хэшем «текст + голос»: правка одного абзаца и перераспределение
  не требуют переозвучивать всю книгу.

## Частые проблемы

* **«triton не установлен — torch.compile отключён»** — работает, но медленнее. Проверь, что
  путь к папке латиницей без пробелов, и перезапусти `install.bat`.
* **Голос немного «плавает»** — используй клонирование (или дизайн → «Использовать этот голос»),
  а не «голос по умолчанию»; добавь точный текст образца; уменьши CFG до 1.6–1.8.
* **Странные главы** — смени режим «Главы» (оглавление/шаблоны/шрифт) и нажми
  «Извлечь из файла заново», или поправь `# заголовки` в тексте вручную.
* **Скан PDF** — сначала распознай (OCRmyPDF, ABBYY FineReader), затем загрузи.
* **Мало места** — один час аудио ≈ 150–200 МБ FLAC в `projects\…\audio`; после сборки эту папку
  можно удалить (если переозвучка больше не нужна).
